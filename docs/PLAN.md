# Delivery plan

## Goal

Deliver a TypeScript + Vite + `bpmn-js` `NavigatedViewer` Omarchy plugin that is statically built, completely local, read-only first, explained through structured sidecars, and operated exclusively through `mise` tasks.

## Roadmap

1. Establish the Omarchy manifest and thin panel boundary.
2. Build the static read-only viewer and local launch path.
3. Import and validate the Nicelydrapped BPMN capability suite.
4. Generate source-grounded diagram and element sidecars.
5. Add navigation, deep links, local file loading, and element selection.
6. Apply active Omarchy colors with accessible and responsive presentation.
7. Enforce security, dependency, bundle, schema, and BPMN quality gates.
8. Add source synchronization without coupling this repository to Nicelydrapped.
9. Package a reproducible release and document installation.

GitHub issues mirror these work packages. The initial repository release completes 1–7; 8–9 remain explicit follow-up work rather than hidden scope.
